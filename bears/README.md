# NOL 좌석 감시 (bears)

NOL 티켓(`tickets.interpark.com`) 좌석 선택 화면을 지켜보다가, 잔여수가 필요한 좌석 수(`SEAT_COUNT`) 이상인 등급이 생기면 아래 순서로 자동 클릭한다.

```
좌석 등급(잔여수 ≥ SEAT_COUNT인 일반석) → 자동 배정받기 → 수량 + (SEAT_COUNT회) → 선택 완료
```

- 새로고침은 하지 않는다. 페이지가 스스로 숫자를 갱신해야 감지된다.
- 누를 등급은 이름 글자로 고른다. `INCLUDE_TEXTS`(포함)에 든 글자가 하나라도 들어간 등급만 대상으로 하고(비우면 전부), `EXCLUDE_TEXTS`(제외)에 든 글자가 하나라도 들어간 등급은 뺀다. 둘 다 여러 개 지정할 수 있다.
- 조건에 맞는 등급이 여러 개 동시에 있으면 `PRIORITY_TEXTS`(우선순위)에 앞에 쓴 글자가 든 등급부터 누른다. 비워 두면 목록 위쪽부터 누른다.
- **이동, 로그인, 캡차는 직접** 한다. 스크립트는 좌석 목록이 뜬 뒤부터 지켜본다.
- PC Chrome 웹 페이지 전용이다.

## 파일

| 파일 | 설명 |
|---|---|
| `run.ps1` | 실행 진입점. venv 생성 → Chrome(디버그 포트) 실행 → 감시 시작 |
| `watch_click.py` | 감시와 클릭 본체. 맨 위 설정 블록 + 클래스(`Logger`, `SeatList`, `StepRunner`, `Watcher`) |
| `clean.ps1` | `.venv` 삭제 (다음 `run.ps1`에서 다시 만들어짐) |
| `watch.log` | 실행 로그 (자동 생성, 계속 이어서 쌓임) |
| `diag.png` | 단계 실패 시 화면 스크린샷 (자동 생성) |
| `.chrome-profile/` | 전용 Chrome 프로필. **로그인 세션이 들어 있음** (자동 생성) |

## 요구 사항

- Windows + Google Chrome (`C:\Program Files\Google\Chrome\Application\chrome.exe`)
- Python 3.10 이상 (`py` 런처로 호출)
- 인터넷 연결

## 사용법

PowerShell에서:

```powershell
cd <이 폴더>
.\run.ps1
```

실행 정책 때문에 막히면:

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

1. 처음에는 `.venv`를 만들고 `playwright`를 설치한다.
2. Chrome이 디버그 포트(9222)로 열린다. **여기서 로그인한다.** (전용 프로필이라 한 번만 하면 된다.)
3. PowerShell로 돌아와 Enter를 누른다.
4. 좌석 목록 화면까지 직접 이동하고 캡차를 통과한다.
5. 터미널에 `START watching ...`이 뜬 상태로 두면 감시 중이다. 조용한 것이 정상이다.
6. 잔여수가 `SEAT_COUNT` 이상인 등급이 생기면 자동으로 클릭하고 `DONE`이 찍힌다. 이후 좌석 선택과 결제는 직접 한다.
7. 종료는 `Ctrl+C`.


## 동작 방식
- `run.ps1`이 **일반 Chrome**을 `--remote-debugging-port=9222`로 띄우고, `watch_click.py`가 Playwright의 `connect_over_cdp`로 그 Chrome에 붙는다. Playwright가 직접 띄운 브라우저는 Google 로그인이 막히기 때문이다.
- 열려 있는 **모든 탭**을 0.3초마다 검사한다. 감시 중에는 좌석 페이지 외의 탭을 열어두지 않는 것이 안전하다.
- 좌석 클릭 후에는 탭을 앞으로 가져오고, 단계별로 버튼이 보이고 활성화될 때까지(최대 10초) 기다렸다가 누른다.
- 단계가 실패하면 좌석을 다시 누르지 않고 멈춘다.


## 설정
바꿀 값은 `watch_click.py` 맨 위 **설정 블록**에만 있다. 아래 표는 각 변수의 의미이고, 지금 실제로 들어 있는 값은 그 파일에서 확인한다.

| 변수 | 의미 |
|---|---|
| `POLL_SEC` | 좌석 목록 확인 간격 (기본 0.3초) |
| `SEAT_CLICK_TIMEOUT_MS` | 좌석 등급 클릭 한도 |
| `STEP_TIMEOUT_MS` | 단계별 버튼 대기 한도 |
| `INCLUDE_TEXTS` | 이름에 이 글자 중 **하나라도** 들어간 등급만 누름. 리스트로 여러 개 지정 (비우면 `[]` = 모든 등급이 대상) |
| `EXCLUDE_TEXTS` | 이름에 이 글자 중 **하나라도** 들어간 등급은 누르지 않음. 리스트로 여러 개 지정 (비우면 제외 없음) |
| `PRIORITY_TEXTS` | 후보가 여러 개일 때 누를 순서. **앞에 쓴 글자일수록 우선** (비우면 `[]` = 목록 위쪽부터). 아래 '우선순위' 참고 |
| `SEAT_COUNT` | 필요한 좌석 수 (기본 `1`). ① **감지**: 등급의 잔여수가 이 값 **이상**일 때만 잡음 (`2`이면 잔여 1은 무시) ② **클릭**: 수량 + 버튼을 이 횟수만큼 누름. 사이트의 1회 최대 수량을 넘기면 + 버튼이 비활성화되어 단계가 실패함 |
| `STEPS` | 좌석 클릭 후 누를 버튼 순서 `(css selector, 글자 정규식)`. 수량 + 버튼은 `SEAT_COUNT`번 자동 반복됨 |
| `SEAT_ITEM` / `SEAT_AVAILABLE` | 좌석 등급 버튼 선택자. `SEAT_AVAILABLE`은 `INCLUDE_TEXTS`, `EXCLUDE_TEXTS`, 잔여수 1 이상으로 자동 조립됨 (`SEAT_COUNT` 이상인지는 코드에서 숫자로 따로 확인) |
| `REMAIN_COUNT` | 등급 버튼 안에서 잔여수가 적힌 요소의 선택자 |
| `CDP_URL` | 붙을 Chrome 주소 (기본 `http://localhost:9222`, `run.ps1`의 포트와 같아야 함) |
| `LOG_FILE` / `SCREENSHOT_FILE` | 로그 파일(`watch.log`)과 실패 시 스크린샷(`diag.png`) 경로 |
| `DIAG_SELECTOR` / `DIAG_EXCLUDE_CLASS` | 단계 실패 시 화면에서 기록할 요소와, 기록에서 뺄 클래스(좌석 목록 버튼) |

포함/제외 예시:

```python
INCLUDE_TEXTS = ["외야", "네이비"]       # 이름에 '외야' 또는 '네이비'가 든 등급만
EXCLUDE_TEXTS = ["휠체어", "시야방해"]   # 그중 '휠체어' 또는 '시야방해'가 든 것은 뺀다
```

| 설정 | 결과 |
|---|---|
| `INCLUDE_TEXTS = []`, `EXCLUDE_TEXTS = ["휠체어"]` | 휠체어만 빼고 잔여석 있는 모든 등급 |
| `INCLUDE_TEXTS = ["외야"]`, `EXCLUDE_TEXTS = []` | 이름에 `외야`가 든 등급만 |
| `INCLUDE_TEXTS = ["외야", "네이비"]`, `EXCLUDE_TEXTS = ["시야방해"]` | `외야` 또는 `네이비` 중 `시야방해`가 아닌 것 |
| `INCLUDE_TEXTS = ["없는글자"]` | 아무것도 안 눌림 (글자를 잘못 쓰면 계속 대기만 함) |

- 글자는 부분 일치이고 영문 대소문자는 구분하지 않는다. 등급 이름뿐 아니라 그 버튼 안의 모든 글자(공지 문구 포함)가 비교 대상이다.
- 포함 조건을 먼저 적용하고 제외 조건을 나중에 적용한다. 같은 글자를 양쪽에 쓰면 아무것도 안 눌린다.
- 글자에 큰따옴표(`"`)는 넣지 않는다.

### 우선순위

포함/제외/`SEAT_COUNT` 조건을 **모두 통과한 후보가 여러 개**일 때 어느 것을 먼저 누를지 정한다.

```python
INCLUDE_TEXTS  = ["1루", "익사이팅", "중앙"]
PRIORITY_TEXTS = ["익사이팅", "중앙", "1루"]   # 익사이팅 > 중앙 > 1루
```

- `PRIORITY_TEXTS`에 **앞에 쓴 글자가 든 등급이 먼저** 눌린다. 위 예시는 익사이팅이 있으면 익사이팅, 없으면 중앙, 그것도 없으면 1루 순이다.
- 이름에 여러 글자가 들어 있으면 **가장 앞 순번**을 따른다. (`NOL존(1루 익사이팅존)`은 `익사이팅`과 `1루` 둘 다 해당하므로 `익사이팅` 순위)
- 우선순위 글자에 하나도 안 걸리는 후보는 **맨 뒤**다. 같은 순위끼리는 **목록 위쪽**이 먼저다.
- 우선순위는 후보 중에서 고르는 데만 쓰인다. 제외 글자나 잔여 부족으로 후보에서 빠진 등급은 우선순위가 높아도 눌리지 않는다.
- 우선순위 글자가 `INCLUDE_TEXTS`에 없어도 된다. 다만 후보가 아니면 아무 효과가 없다.
- 클릭하면 로그에 어떤 우선순위가 적용됐는지 남는다: `SEAT CLICKED: NOL존(1루 익사이팅존) | 5 | priority #1 '익사이팅'`.

예시 (후보가 `NOL존(1루 익사이팅존)`, `중앙 네이비석`, `DB손해보험존(1루 테이블석)`이고 모두 잔여가 있을 때):

| `PRIORITY_TEXTS` | 눌리는 등급 |
|---|---|
| `[]` | `DB손해보험존(1루 테이블석)` (목록 위쪽) |
| `["익사이팅", "중앙", "1루"]` | `NOL존(1루 익사이팅존)` |
| `["중앙", "익사이팅"]` | `중앙 네이비석` |
| `["익사이팅", "중앙", "1루"]` (익사이팅 매진) | `중앙 네이비석` |

## 로그

콘솔과 `watch.log`에 같은 내용이 `[연-월-일 시:분:초.밀리초]` 형식으로 남는다.

| 로그 | 의미 |
|---|---|
| `START watching ...` | 감시 시작 (열린 탭 목록 포함) |
| `SEAT LIST FOUND (N items)` | 좌석 목록이 보이기 시작함 (감시 재개) |
| `SEAT LIST LOST` | 좌석 목록이 사라짐 (이동, 10분 타임아웃으로 튕김 등) |
| `RETRY: ...` | 탭 이동 중 등 일시적 에러. 같은 메시지는 연속으로 한 번만 기록 |
| `SEAT SKIPPED (remain < SEAT_COUNT=N): ...` | 잔여는 있지만 `SEAT_COUNT`에 모자라서 무시한 등급. 같은 내용은 한 번만 기록 |
| `SEAT CLICKED: <등급 \| 잔여수> [\| priority #n '글자']` | 잔여수가 `SEAT_COUNT` 이상인 후보 중 우선순위가 가장 높은 등급을 클릭함. 우선순위 글자에 걸렸으면 몇 번째였는지 함께 표시 |
| `STEP n/N OK: ...` | n번째 단계 성공 (단계 시간, 좌석 클릭 후 누적 시간). N은 전체 단계 수 = 2 + `SEAT_COUNT` |
| `STEP n/N FAILED` | 실패한 단계, 에러, 화면의 버튼 목록. `diag.png`도 저장 |
| `DONE. holding browser` | 단계 종료. 브라우저는 열어둠 |
| `STOPPED by Ctrl+C` / `CRASHED` | 종료 / 예상 못 한 에러(traceback 포함) |

## 문제 해결

| 증상 | 해결 |
|---|---|
| `Python` 한 줄만 나오고 끝남 | Windows Store 가짜 `python`이 잡힌 것. `run.ps1`은 `py` 런처를 쓰므로 `py --version`이 되는지 확인 |
| 접속 오류 (`connect_over_cdp`) | Chrome이 디버그 포트 없이 이미 떠 있음. Chrome을 완전히 닫고 `run.ps1`로 다시 실행 |
| `STEP n/N FAILED` | 로그의 `buttons on screen`에서 실제 버튼 글자와 클래스를 확인해 `STEPS`를 고침 |
| 처음 한 번 Google 로그인 차단 | 이 방식(일반 Chrome 접속)을 써야 함. Playwright로 직접 띄운 브라우저는 차단됨 |
| 한글이 깨져 보임 | `.ps1`은 UTF-8 BOM으로 저장해야 한다. BOM 없이 저장하면 PowerShell 5.1에서 깨짐 |

## 주의
- `.chrome-profile/`에는 **로그인 쿠키**가 있다. 공유하거나 커밋하지 않는다. (`.gitignore`는 이 폴더가 아니라 **상위 폴더**에 있고, `.chrome-profile/`, `.venv/`, `__pycache__/`, `*.log`, `*.png`를 무시한다. 이 폴더만 따로 떼어 저장소로 쓸 땐 `.gitignore`를 같이 옮긴다.)
- 매크로 사용은 서비스 약관 위반일 수 있고, 감지되면 예매 제한이나 계정 제재가 있을 수 있다. 사용에 따른 책임은 사용자에게 있다.
- 사이트 구조(클래스명, 버튼 글자)가 바뀌면 `watch_click.py` 설정 블록의 선택자를 고쳐야 한다.
